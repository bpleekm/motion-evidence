# ADR-0001：受界限的视觉取证

状态：接受。

模型负责观察实际活动和提出帧边界，程序拥有源身份、可读/可编辑范围、政策映射和最终时间线。全景及连续帧通过明确工具获取，模型不能仅引用文件名假装看过。

采用Responses图像输入、function calling和Structured Outputs；schema解决格式，业务校验解决范围/证据/覆盖，两者都不等于语义正确。

人物静坐/睡觉/静止站立均允许加速，故不设置“有人即保留/即送审”。旧像素证据可重用，旧人物保护决策不直接继承。未决保留并hold，待数据补齐后恢复。

文件协议优先于跨仓库代码导入。原session只读；所有私有数据、密钥和运行结果位于本地env或外部工作根，公开测试只用合成素材。
