# 验证

## 离线必需测试

- 同一人检字段变化不单独改变送审；分支异或/低档候选正确触发。
- 锁定区间从候选中扣除且合并后保持；任务无越界，时间线无洞/重叠。
- 可变PTS合成视频：指定帧精确取出、ROI与原尺寸正确、重复请求命中缓存，不以附近帧代替。
- 即使产物SHA已更新，帧ID/stream/time_base/ms/尺寸与源清单不符仍拒绝；跨文件起点与原PTS基准按有理数复算。
- 连续帧工具先检查完整请求范围，不能通过稀疏采样掩盖越界；上游GPU人检hold在prepare/report中保持。
- 模拟API确实收到image对象、能够请求连续帧/局部、call_id与完整响应历史正确传回。
- 非法帧引用、未查看边界、单时间证据、错误覆盖均被拒绝；接口错误不会进入static。
- .env缺失时hold；异常字符串中的密钥不进入日志；累计调用预算和恢复生效。
- 两仓库合成主流程同时覆盖有裁决与缺失配置hold两条路线。

## 真实质量验收

按新规则审核的正/负例独立验收争议漏召、活动保留、静止误保留和边界。旧“人物存在即保留”的标注不自动复用。中心帧事实不扩大为整段真值。

记录模型/提示词/规则/输入/evidence指纹、图像和token数量、实际usage、取证解码次数与缓存命中、端到端耗时。模拟API仅验证软件协议，不报告为AI识别准确率。

所有真实测试产物在外部私有根。源工作区只读，GPU旧性能不当作本项目成绩。
